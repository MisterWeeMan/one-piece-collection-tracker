Importazione multipla

Una carta per riga: codice | nome | set | rarità | L (rarità e "L" finale sono opzionali; "L" indica una carta Leader con obiettivo 1x). Le righe già usate in formato precedente, senza colonna rarità, restano valide. In alternativa puoi incollare un array JSON con i campi code, name, set, rarity, leader.

Sincronizzazione tramite Gist (vecchio metodo)

Collega l'app a un Gist privato del tuo account GitHub: i dati vengono salvati lì e li ritrovi su qualsiasi altro dispositivo. Serve un Personal Access Token con permesso "gist" — crealo qui (scegli "Generate new token (classic)", spunta solo la casella "gist", genera e copia il token).

Connesso. Su ogni altro dispositivo apri questo stesso pannello e inserisci lo stesso Gist ID con un token valido per collegarti allo stesso archivio.
